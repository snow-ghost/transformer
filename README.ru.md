# Проверяемый вероятностный классификатор

Самостоятельный Lean 4-проект: контекст, программа и память задают распределение
по классам; отдельная операция возвращает таблицу вероятностей и класс с
максимальной вероятностью. Добавлены температура, обучение по наблюдениям,
признаки, критерий качества и статистические гарантии выбора модели.

Jev здесь служит аналогией интерфейса. Проект не доказывает корректность
внутреннего алгоритма Jev и не реализует Transformer attention.

## Запуск

Нужны `elan` и Python 3. Версии Lean и зависимостей закреплены в репозитории.

```sh
python3 scripts/fetch_cache.py
lake build
python3 scripts/check.py
lake exe classifierDemo
```

Демонстрация с тремя классами получает вероятности **5/8, 1/4, 1/8** и выбирает
класс 0. На неизвестном контексте прогноз равномерный; при равенстве
вероятностей выбирается первый класс. Пример проверен ядром Lean.

## Что доказано

- Нормировка вероятностей, существование максимума, корректность выбора класса.
- Свойства softmax и положительной температуры, сохранение множества максимумов.
- Частотное обучение со сглаживанием, сохранение других контекстов и точное
  соответствие исполняемого многоклассового ученика математической модели.
- Минимальность Brier-риска для истинного распределения.
- Восстановление распределения по достаточному признаку и условная сходимость.
- Оптимальность конечного поиска и статистические гарантии на свежей
  независимой проверочной выборке для конечного каталога бинарных моделей.

Всего **106 именованных теорем и 5 вычислительных примеров**.
[Индекс теорем](docs/THEOREMS.md) связывает результаты с исходниками.
Проверка аксиом охватывает все именованные теоремы; дополнительных аксиом,
незавершённых доказательств и `native_decide` нет.

Нормировка не доказывает точность относительно неизвестного источника.
Сходимость требует явно сформулированных предпосылок о данных. Статистические
результаты выбора модели в этом выделенном наборе относятся к двум классам;
общий классификатор и исполняемый частотный ученик допускают больше классов.
Корректность конкретного PRNG, вычислений на `Float` и обобщение на произвольные
реальные данные не установлены. Подробные условия перечислены в
[основном README](README.md).
